CFF Deobfuscator

view code

Rebuilds the original control flow of programs hidden by control-flow flattening, a technique used to slow down reverse engineering. My MSc Cybersecurity dissertation at the University of Manchester.

Python and angr, tested on Tigress-obfuscated zlib and sqlite. On sqlite, it found the dispatcher in 77% of 1,199 functions, and 57% of all functions came within 2 of the original complexity.

Codename

view code

Look up a hacker group by any of its names, see who named it, and learn what names like "Panda" or "Typhoon" mean. Every group and name links to its source.

FastAPI, PostgreSQL, React, TypeScript, Docker and GitHub Actions. Built with AI assistance. The first search can take about a minute while the free server wakes up.

Compromised Account Playbook

view repo

An incident response playbook for hijacked cloud email accounts, with a case study of the 2026 Nikkei breaches built from public reporting.

Separates what was reported from what is unknown, and includes severity levels, triage steps, MITRE ATT&CK mapping and example KQL queries.
